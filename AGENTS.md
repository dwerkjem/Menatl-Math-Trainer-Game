# AGENTS.md: Rules for AIs and AI-assisted tools

This project is mostly human-written. Read this whole file before writing anything.

## Scope

1. Make small edits. Do not rewrite code unless a human gives explicit permission.
2. Prefer explaining things over writing things.

## Disclosure

All code you (the AI) write must be marked. Use the file's own comment syntax (`#`, `//`, `--`, `<!-- -->`, etc.).

Dates are always written as `MM-DD-YYYY`, for example `11-10-2026`.

Never include links of any kind in these comments.

### Inline

If you write a single line of code, you must add a comment at the end of it in this format:

`Generated by <name>:<model> on <MM-DD-YYYY>`

Example:

```python
import re

text = input("Enter text:")
has_phone = bool(
    re.search(
        r"(?<!\d)(?:\+?1[ .-]?)?(?:\([2-9]\d{2}\)|[2-9]\d{2})[ .-]?[2-9]\d{2}[ .-]?\d{4}(?!\d)",
        text,
    )
)  # Generated by Claude:Opus5.5 on 11-10-2026
if has_phone:
    print("Do not enter phone numbers here.")
else:
    print("Thanks bye!")
```

If you edit part of an existing line, you must add a comment in this format:

`Edited from column <start> to <end> by <name>:<model> on <MM-DD-YYYY>`

Columns start at 1, and the end column is included. Count carefully. If you are not sure of the exact columns, write `Partially edited by <name>:<model> on <MM-DD-YYYY>` instead.

Example (the regex string, columns 28 to 114, was edited):

```python
has_phone = bool(
    re.search(r"\(\d{3}\)-\d{3}-\d{4}(?!\d)", text)
)  # Edited from column 28 to 57 by Claude:Opus5.5 on 11-11-2026
```

### Block

Any AI-written code longer than one line is a block and must be wrapped in start and end markers.

```python
# AI-GENERATED START by <name>:<model> on <MM-DD-YYYY>
def is_valid(text):
    return bool(re.search(PHONE_PATTERN, text))


# AI-GENERATED END
```

Rules:

- Every START must have exactly one END after it.
- Blocks must not be nested inside each other.
- If you edit an existing human-written block, use `AI-EDITED START` / `AI-EDITED END` around only the lines you changed.
- If a human later rewrites AI code, they remove or update the markers. Do not remove markers yourself.
